# Glowing Key Garden

This is my little web toy. Each key you press blooms a soft patch of coloured light and plays a gentle note to go with it.

The notes come from a calm five-note scale, so whatever you mash sounds friendly. The same key always gives the same colour and the same note. Letter keys bloom where they sit on a keyboard, and tapping the screen blooms a patch right under your finger, for phones.

New in step 5: the patches now fade slowly away over a few seconds, shrinking and dimming until the garden is dark again and falls back asleep.

To try it, open the page and press lots of keys, then watch the lights drift off.
